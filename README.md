# 🐸 奶蛙桌宠 · 三宠陪伴

一只住在你 Windows 桌面上的可爱桌宠，三只宠物任你切换陪伴：**奶蛙**、**凑企鹅**、**大狗**。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🪟 桌面悬浮 | 无边框透明窗口，始终置顶，不占任务栏 |
| 🐸🐧🐶 三宠切换 | 奶蛙 / 凑企鹅 / 大狗，主菜单一键切换 |
| 🏀 物理甩动 | 拖拽快速松手甩出去：重力下落、边缘反弹、挤压形变 |
| 🌀 三宠蓄力 | 按住蓄力（音效循环加速），松手发射（越久越慢），点击过快快放 |
| 🐸 奶蛙 · 大笑 | 绿幕抠图透明播放"奶龙大笑"视频，用大笑音效"说话" |
| 🐧 凑企鹅 · 唱歌 | 循环播放 sing 动画 + 音乐，控制栏切歌/暂停/下一首 |
| 🐶 大狗 · 听歌 | 切换 dog3 形象听歌，控制栏操控 |
| 💬 AI 对话 | 接入任意 OpenAI 兼容大模型 API（DeepSeek 等） |
| 🧠 对话记忆 | 奶蛙记住聊过的内容，跨会话持久化（主菜单可清空）|
| 🎭 人格化 | 三宠各有性格：奶龙梗 / 高松灯 / 叮咚鸡大狗叫 |
| ⏱️ 陪伴时长 | 跨会话累计陪伴分钟数 |

## 🚀 快速开始

### 方式一：下载 exe
1. 从 [Releases](../../releases) 下载最新版压缩包
2. 解压到任意文件夹
3. 双击 `naiwa-pet.exe` 运行

> **素材文件必须与 exe 同目录**（各宠物图片、视频、音频）

### 方式二：源码运行
需要 Python 3.11+ 和 pip：
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python pet.py
```

## 💬 配置 AI 对话
1. 右键桌宠 → **主菜单**
2. 填写 API 配置（Base URL / API Key / 模型名），支持任意 OpenAI 兼容接口
3. 保存后右键 → **对话**，桌宠以各自性格回复

## 🎮 操作指南

| 操作 | 效果 |
|------|------|
| 左键拖动 | 移动桌宠 |
| 左键快速甩动松手 | 物理甩出 |
| 右键 | 自定义菜单（功能随桌宠变化）|
| 主菜单 | 切换桌宠 / API 配置 / 清空记忆 |

### 各桌宠专属操作
- 🐸 **奶蛙**：按住蓄力（音效随机抽取）→ 松手发射（变 naiwa4 形象）；右键切换形象 / 大笑 / 对话
- 🐧 **凑企鹅**：按住蓄力（咕咕嘎嘎）→ 松手发射（变 tomorin2 形象）；右键跳舞 / 飞踢 / 唱歌
- 🐶 **大狗**：按住蓄力→松手咆哮（变 dog2 形象）；右键听歌（切 dog3 形象）

## 🎵 自定义歌曲

想让大狗/凑企鹅帮你播放你喜欢的歌？超简单：

- **大狗**：把歌曲放进 `dog/music/` 文件夹
- **凑企鹅**：把歌曲放进 `tomorin/music/` 文件夹

支持 **mp3 / m4a / wav / ogg / flac** 格式。放入后重启桌宠，右键 → **听歌/唱歌** 就会自动包含你的歌曲（控制栏可切歌/暂停/下一首）。

## 🛠️ 技术栈
- **语言**：Python 3.11
- **GUI**：tkinter（无边框透明窗口，magenta 色键透明）
- **视频**：imageio + imageio-ffmpeg（逐帧解码 + 绿幕色键抠图 + 变速）
- **音频**：pygame（音效变速、音乐播放）
- **打包**：PyInstaller
